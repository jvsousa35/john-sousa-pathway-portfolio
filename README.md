# John Sousa Pathway Portfolio

This repository contains my final project portfolio website for an aspirational professional identity: **Head of College Pathway & Player Recruitment**.

After GitHub Pages is turned on, add the live link here:

## Project Purpose

This website presents the professional direction I am building toward: creating organized player pathway and recruitment systems for academy players who want to pursue college and professional opportunities.

The portfolio is built around a realistic role connected to my current experience in soccer:

- Head of College Pathway & Player Recruitment
- U15 MLS NEXT Pre-Professional Head Coach
- USL2 Analyst & Assistant Coach
- Academy player development and recruitment work

## Site Pages

- `index.html` — professional identity, hero section, resume snapshot, and pathway preview
- `pathway.html` — full academy pathway system, seven-phase model, and U15-U19 recruitment timeline
- `projects.html` — four portfolio case studies connected to recruitment and player pathway work
- `workflow.html` — skills, tools, and AI workflow explanation
- `contact.html` — contact information and future vision

## Featured Portfolio Projects

1. **College Pathway Department Model**  
   A full club-wide system for player and family recruitment support.

2. **Player Recruitment Profile System**  
   A profile structure that helps college coaches quickly understand a player's level, academics, video, strengths, and target schools.

3. **Showcase & College Coach Outreach Workflow**  
   A workflow for preparing players before showcases through school matching, coach outreach, profile sharing, and follow-up tracking.

4. **Player & Parent Education Program**  
   A workshop and meeting model to educate families on timelines, communication standards, scholarships, financial reality, and right-fit schools.

## How to Run Locally

Open `index.html` in a browser, or host the repository through GitHub Pages.

## GitHub Pages Setup

1. Upload all files in this repository to GitHub.
2. Go to **Settings**.
3. Click **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save.
7. Use the live site URL in this README and submit the repository link.
